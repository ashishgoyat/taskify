# 📝 Kanban Todo Board (Drag & Drop)

## 📌 Project Overview
This project is a **Kanban-style Todo Board** built using **HTML, CSS, and Vanilla JavaScript**.  
It allows users to create tasks and move them across different workflow stages using **drag and drop**.

The application focuses on:
- Clean UI/UX
- Functional drag-and-drop behavior
- Proper state separation using columns

---

## 🎯 Features
- ➕ Add new todo cards dynamically
- 🧲 Drag and drop cards between columns
- 🗂️ Workflow stages:
  - Todo
  - In Progress
  - Under Review
  - Completed
- 🚦 Task urgency levels:
  - Low
  - High
  - Urgent
- 🌙 Modern dark theme UI
- 📅 Automatic date creation for tasks
- 📱 Responsive layout (mobile & desktop)

---

## 🧠 Concepts Used
- DOM Manipulation
- HTML5 Drag and Drop API
- Flexbox & Grid Layout
- Event Handling in JavaScript
- CSS Dark Theme Design
- Dynamic Element Creation
